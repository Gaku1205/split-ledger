# デザイン仕様

split-ledger の画面の見た目のルール（色・文字・形・文言・動き）。画面に触る作業では、ここに書かれた物だけを使う。

## 1. 使う場面

- **使う人**：一緒に暮らすルームメイト（2〜4人）や、旅行・飲み会の友達（3〜6人）。20〜30代で、スマホのアプリには慣れているが、表計算で割り勘を組むほどの手間はかけたくない人。（推定）
- **使う場面**（推定）
  - **記録**：立て替えた直後。スーパーのレジを出た所、店を出た帰り道、旅先の移動中。立ったまま片手で、1回15〜30秒。週に数回〜旅行中は1日に何回も
  - **確認・精算**：月末、旅行の最後の夜、「そろそろ精算しよう」と言われたとき。テーブルを囲んで1台のスマホを何人かで覗くか、各自のスマホで開く。1回1〜3分
- **端末と姿勢**：スマホが主（390・360px）。記録は片手・親指で、明るい屋外や店内でも読めること。PC は、家で月末にまとめて記録を見直すときだけ使う。（推定）
- **やりたいこと（優先順）**
  1. **誰が誰にいくら返せばいいかを知る**（いちばん大事）
  2. 立て替えを1件記録する
  3. 記録を見直す・間違いを直す
  4. 自分の差し引き（多く払っているか、足りないか）を知る
- **見たい情報（優先順）**
  1. 返す組と金額（「田中さん → 佐藤さん 6,210円」）。最初の1画面に必ず入れる
  2. 「立て替えを記録」の操作。最初の1画面に必ず入れる（スマホでは画面の下に固定）
  3. ひとりずつの差し引き（受け取る／返す／0円）
  4. 最近の立て替え（何に・いくら・誰が払ったか）
- **気持ち**：開く前は「お金の話は気まずい」「計算が面倒」。開いた後は「数字がはっきりしているから、誰も損していないと言い切れる」という安心。言い出す人が責められない、事務的で落ち着いた見た目にする
- **失敗すると困ること**
  - 返す向きの読み間違い（誰が払う側か）。人間関係にひびが入る
  - 金額の打ち間違い（桁の多い・少ない）、払った人の選び間違い
  - 記録を消してしまう
  - 数字の読み間違い（3と8、桁区切りの無い大きな数）

## 2. サービスの型と優先順位

**型：管理・記録の道具。** 毎回の記録と、ときどきの確認を繰り返す道具なので、見た目の個性より、入力の速さ・返す向きと金額の読みやすさ・間違えにくさを優先する。飾り・大きな演出・入場の動きは入れない。質は、数字の桁揃え・整列・余白・線の細さで出す。

**この画面が答える1つの問い**：「誰が、誰に、いくら返せばいいか」。画面でいちばん大きい数字は、この答えの金額にする。

**参考にした仕組み**（色・ロゴ・書体は写していない）

- Wise：お金を動かす画面の中心に「金額の入力欄」を1つ大きく置き、ほかの欄はその下に並べる仕組み。記録のフォームで、金額を最初・最大にするために使う。面の差（白い面と、色の付いた地）だけで重なりを見せ、影を使わない所も使う
- Mercury：太さを増やさず、大きさと色の濃さで階層を付ける仕組み。太字をお金だけに使うために使う
- Revolut：狭い画面ではメニューを畳んでも、主な操作のボタンだけは常に見える所に残す仕組み。スマホで「立て替えを記録」を下に固定するために使う

**taste-skill で選んだ方向**：`draw.mjs --app --kind wallet` で配られた2つ（`achromatic-ledger`・`pastel-consumer`）から、**`achromatic-ledger`（色の無い帳簿）** を選んだ（seed 1206939658）。理由：サービス名どおり「帳簿」で、数字を事務的に読ませたい。`pastel-consumer` の淡い色のタイルは、カテゴリの多い家計簿向きで、この画面には分類が無く、色が増えると返す向きより色に目が行く。

- 方向から使う物：画面の枠には色を使わない。主な操作は黒に近い塗り。色相は1つ（青）だけで、画面の主なデータ（返す組の矢印）に置く。角丸は 8px と 6px の小さい組。影は浮く物（シート・通知）だけ
- 方向の「顔」から選んだ物：地を、帳簿らしい青みの灰色（`#F2F4F7`）にする
- このサービスだけの要素：**返す組の行**（払う人の印 → 受け取る人の印、金額）。1本の矢印だけに色相を置き、向きを形で読ませる
- 変えた所：配られた欧文書体 Geist は、数字と欧文だけに使い、日本語は BIZ UDPゴシックにする（日本語の画面のため）。配られた殻（上のバー＋中央の段）は使うが、リンクの列と検索は置かない（行き先が1画面しか無いため）

## 3. 構図

### 共通

- 1画面の作りで、上から「上のバー → グループ名（h1）と1行の要約 → 返す人と金額 → ひとりずつの差し引き → 立て替えの記録」
- 余白は 4px を単位にする。ブロックの間は 16px（スマホ）・24px（PC）の1種類だけ
- 面の作り：地 `--ground` の上に、白い面 `--surface`（1px の線 `--border`、角丸 8px、影なし）を置く

│ └──────────────────────────┘ │
│                              │

- 左右の余白 16px。面の中の余白 16px
- 上のバー：高さ 48px、地の色。左に印と名前、右に「メニュー」ボタン（44×44px、≡ の線3本、`aria-label="メニュー"`）。上のバーは固定せず、ページと一緒に流れる（下に固定の帯があるので、上まで固定すると狭い画面で内容の見える高さが減るため）。線は引かない
- h1 は上のバーの下 16px から
- 「立て替えを記録」は画面の下に固定する（親指が届く所。記録は立ったまま片手でするため）。地の色の帯（上に 1px の線 `--border`）の中に、左右 16px・上 12px・下 `12px + env(safe-area-inset-bottom)` で、幅いっぱい・高さ 48px のボタン。ページの下に、この帯の高さぶんの余白（`padding-bottom: calc(72px + env(safe-area-inset-bottom))`）と `scroll-padding-bottom` を同じ値で付け、フォーカスした物が帯の下に隠れないようにする
- 390×844 の最初の1画面に、h1・要約・返す組（3行まで）・「立て替えを記録」が入る（上のバー48＋h1と要約70＋見出し40＋3行192＋固定の帯72＝422px、余りがある）
- 360px でも同じ並び。名前は省略（…）して、金額は省略しない

### タブレット（641〜1023px）

- スマホと同じ1列。段の幅は最大 640px で、中央に置く。「立て替えを記録」も同じく下に固定（帯の中でボタンは幅 640px まで、中央）。記録のシートも幅 640px まで、中央

### PC（1024px 以上）

```
┌────────────────────────────────────────────────────────────┐
│ ⧄ split-ledger                                 ≡ メニュー  │ 48px
│ 301号室                                                    │
│ 4人で12件、合計48,620円                                     │
│ ┌──────────────────────────────┐  ┌────────────────────┐   │
│ │ 返す人と金額                  │  │ 立て替えを記録      │   │
│ │ (田)田中 ──→ (佐)佐藤  6,210円 │  │ 金額 [        円]   │   │
│ │ …                             │  │ 何に [          ]   │   │
│ └──────────────────────────────┘  │ 払った人 (佐)(田)…  │   │
│ ┌──────────────────────────────┐  │ 誰の分   [佐][田]…  │   │
│ │ ひとりずつの差し引き          │  │ 日付 [          ]   │   │
│ │ (佐)佐藤  ──┼▬▬▬ 受け取る …   │  │ [ 記録する ]        │   │
│ └──────────────────────────────┘  └────────────────────┘   │
│ ┌──────────────────────────────┐                           │
│ │ 立て替えの記録                │                           │
│ │ スーパー            4,620円   │                           │
│ └──────────────────────────────┘                           │
└────────────────────────────────────────────────────────────┘
```

- 段は中央に置き、幅は最大 1088px（左右の余白は最低 24px）。1024px では内容の幅 976px
- 2列：`grid-template-columns: minmax(0, 1fr) 400px; gap: 24px;`（1088 = 664 + 24 + 400）。左の列は「返す人と金額」→「ひとりずつの差し引き」→「立て替えの記録」（スマホと同じ、見たい情報の順。1024×768 でも差し引きまでが最初の1画面に入る）。右の列は「立て替えを記録」だけ（フォームを常に開いておく。家でまとめて入れるときに、開け閉めの手間を減らすため）
- 右の列のフォームは `position: sticky; top: 24px;`。左の記録を下まで見ていっても、フォームが見えたままになる（見直しながら足すため）。フォームが画面の高さより高いときは固定しない（`max-height` を超える分が隠れないように、`@media (min-height: 760px)` のときだけ sticky）
- 2つの列はそれぞれ上から積み、高さを揃えるために面を引き伸ばさない（`align-items: start`。中身の少ない面に空白の帯を作らないため。列の下端は揃わなくてよい）
- 下に固定する帯は出さない
- 2560px でも段は 1088px のまま中央。左右は地の色が広がるだけで、面を横に伸ばさない（行の名前と金額の間が間延びするため）

## 4. 色

明るい場所（店内・屋外）で片手で読むので、明るい地にする。色相は青1つだけで、返す組の矢印とフォーカスにだけ使う。お金の増減に赤・緑を使わない（「受け取る」「返す」の言葉と符号で伝える。返す側を赤にすると責めているように見えるため）。

| 名前 | 値 | 用途 | コントラスト比 |
| --- | --- | --- | --- |
| `--ground` | `#F2F4F7` | ページの地、上のバー、下に固定する帯 | — |
| `--surface` | `#FFFFFF` | 面（返す組・差し引き・記録・フォーム）、入力欄の中 | — |
| `--raised` | `#E6E9EF` | 乗せた・押したときの行の地、2番目のボタンの地、読み込み中の棒 | — |
| `--border` | `#DFE3EA` | 面の外枠、上のバーと帯の線 | 白に対して 1.3:1（区切りの線なので文字の基準は当てない） |
| `--rule` | `#EDEFF3` | 面の中の行の区切り | — |
| `--control` | `#8A91A0` | 入力欄・選ぶ札の枠、差し引きの棒 | 白に対して 3.2:1（部品の境目の 3:1 を満たす） |
| `--text` | `#16181D` | 本文、名前、金額、見出し | 白に 17.8:1、地に 16.1:1 |
| `--muted` | `#596070` | 弱い文字（要約、日付、補足、単位の「円」、入力欄の例） | 白に 6.3:1、地に 5.7:1、`--raised` に 5.2:1 |
| `--primary` | `#16181D` | 主なボタンの地（文字は `#FFFFFF`）、選んだ「払った人」の札の地 | 白い文字が 17.8:1 |
| `--primary-hover` | `#2C3038` | 主なボタンに乗せたとき | 白い文字が 13.2:1 |
| `--signal` | `#1D5FBF` | 返す組の矢印、フォーカスの輪 | 白に 6.1:1、地に 5.5:1 |
| `--negative` | `#B42318` | 入力のエラーの文字と枠、「この記録を消す」 | 白に 6.6:1、地に 6.0:1 |
| `--negative-bg` / `--negative-ink` | `#FDECEB` / `#8A1C14` | 読み込み・保存の失敗の知らせの地と文字 | 8.2:1 |

**人の印（名前の頭文字の丸）の色**：人を見分けるための淡い色。データの色ではないので、棒や矢印には使わない。メンバーに足した順に1〜6を割り当て、7人目からは1に戻る。隣どうしの色相は60度以上離れる順にしてある。頭文字があるので、色だけで人を見分けさせない。

| 1 | `#DDE9F7` | `#1B3F6B` | 8.7:1 |
| 2 | `#F6EAD2` | `#5C3D0B` | 8.3:1 |
| 3 | `#DCF0E4` | `#1D4D32` | 8.2:1 |
| 4 | `#F6DDE8` | `#6B1F3F` | 8.7:1 |

- 画面の中で色の付いた所は、矢印と人の印だけ。面の地・ボタン・見出しに色相を使わない
- `<meta name="theme-color" content="#F2F4F7">`。`color-scheme: light`（暗い画面は作らない。使う場面が明るい所のため）

## 5. 文字

- 書体（Google Fonts）：
  - **Geist**（400・500・700）：数字と欧文。字の幅が揃う数字（`font-variant-numeric: tabular-nums`）が出せ、3と8、1と7の形がはっきり違うので、金額の桁を縦に揃えて読み間違いを減らせる
  - **BIZ UDPゴシック**（`BIZ UDPGothic`、400・700）：日本語。読み間違いを減らすために作られた UD 書体で、小さい字でも濁点・半濁点が潰れにくい（明るい屋外で片手で読むため）
  - 指定：`font-family: "Geist", "BIZ UDPGothic", system-ui, sans-serif;`（欧文と数字は Geist、日本語は BIZ UDPゴシックで出る）。`next/font/google` で読み込み、`display: swap`。BIZ UDPゴシックは日本語の字が大きいので `preload: false`（ブラウザが使う分だけ取りに行く）
- 数字は全部 `font-variant-numeric: tabular-nums`。表や一覧の金額は右揃え
- 太さ：700 を使うのは、お金の金額・h1・面の見出し・欄のラベル・主なボタンの日本語だけ（BIZ UDPゴシックに 500 が無く、見出しの段を付けるのに 700 が要るため）。それ以外は 400。Geist の 500 は、上のバーの「split-ledger」、ボタンの欧文と数字、欧文の頭文字に使う
- 見出しの順：h1 はグループ名、面の見出しは h2。見出しは `text-wrap: balance`
- 大きさの段（5段）：

| 役 | 大きさ / 行の高さ | 太さ | 使う所 |
| --- | --- | --- | --- |
| 答えの金額 | 24px / 32px | 700 | 返す組の金額、金額の入力欄 |
| h1 | 20px / 28px | 700 | グループ名 |
| 見出し・大きい本文 | 16px / 24px | 700（見出し）・400（本文） | 面の見出し、名前、記録の「何に」、入力欄の文字（iOS が勝手に拡大しないよう 16px） |
| 本文 | 14px / 22px | 400 | 要約、差し引きの金額、記録の金額、ラベル、ボタン、エラー |
| 小さい文字 | 12px / 18px | 400 | 日付、補足の行、単位の「円」（14px の数字の横）、人の印の頭文字 |

- 金額の書き方：`Intl.NumberFormat("ja-JP")` で桁区切りを付け、後ろに「円」。円は数字より1段小さく `--muted`（24px の数字なら 14px、14px の数字なら 12px）。「¥」は使わない（`ja-JP` の通貨書式は全角の「￥」になり、桁が揃わないため）
- 符号：差し引きは「受け取る」「返す」の言葉で書き、符号を付けるときはマイナスに `−`（U+2212）を使う
- 0円は「0円」と書く（ダッシュにしない）。値が無い所は `--muted` の「—」
- 日付：`Intl.DateTimeFormat("ja-JP", { month: "long", day: "numeric" })`（「10月28日」）。今年でないときだけ年を付ける。サーバーとブラウザで日付がずれないよう、日付の文字はブラウザで作る
- 11.5px より小さい文字は使わない。大文字だけのラベル・字間を広げたラベルは使わない
- 日本語は文節の途中で切らない（`word-break: auto-phrase`）。サービス名 `split-ledger` には `translate="no"`

## 6. 部品と状態

フォーカスは全部の押せる物で同じ：`:focus-visible` に `outline: 2px solid var(--signal); outline-offset: 2px;`。`outline: none` だけにしない。動きは `transition` に変える性質を書き並べる（`all` を使わない）。押せる物には `touch-action: manipulation` と `-webkit-tap-highlight-color: transparent`（押した見え方は下の「押した」で出すため）。「乗せた」の見え方は `@media (hover: hover)` の中だけに書く（スマホで指を離した後も乗せた色が残らないように）。

✓・丸で囲んだ「!」・≡・矢印などの記号は、全部 SVG で描き `aria-hidden="true"`（文字の ✓ は端末によって絵文字で出るため）。線の太さは 1.5px（矢印だけ 2px）、色は横の文字と同じ。

### 上のバーと印

- 印：20×20px の SVG。角丸 4px の正方形の線（1.5px、`--text`）に、左下から右上への対角線を1本（「割る」帳簿）。`aria-hidden="true"`。印の 8px 右に「split-ledger」（Geist 500、16px、`--text`）
- メニュー：44×44px、≡（線3本、16px 幅、1.5px、`--text`）。乗せた：地 `--raised`、角丸 6px。PC（1024px 以上）では ≡ の右 8px に「メニュー」（14px、`--text`）を出し、ボタンの幅は内容まで（左右の余白 12px、高さ 36px）。文字が見えるので `aria-label` は付けない
- メニューを開くと、スマホ・タブレットは全画面のシート、PC は右端から幅 400px・高さいっぱいの面（後ろに記録のシートと同じ幕）。どちらも地 `--surface`、`overscroll-behavior: contain`、右上に「閉じる」（2番目のボタン）。メンバーの一覧などが並ぶ（中身は仕様書に従う）。開いたら「閉じる」にフォーカス、閉じたら「メニュー」に戻す。Esc でも閉じる

### 主なボタン（1画面に1つ：「立て替えを記録」「記録する」「変更を保存」）

| 状態 | 見え方 |
| --- | --- |
| 通常 | 高さ 48px、地 `--primary`、文字 `#FFFFFF` 16px（Geist 500 / BIZ UDPゴシック 700）、角丸 6px、左右の余白 20px。枠・影なし |
| 乗せた | 地 `--primary-hover` |
| 押した | 地 `--primary`、`transform: scale(0.98)` |
| フォーカス | 上の共通の輪 |
| 使えない | 保存中だけ。地 `--raised`、文字 `--muted`、文言「記録中…」。入力が足りないだけでは使えなくしない（押したらエラーを出す） |

### 2番目のボタン（「閉じる」「元に戻す」「もう一度読み込む」など）

- 高さ 44px（PC は 36px）、地 `--raised`、文字 `--text` 14px、角丸 6px。乗せた：地 `#DADEE6`。押した：`scale(0.98)`
- 文字だけの押せる物（「すべての記録（12件）」「全員」）：文字 `--text` 14px、下線 1px（`text-underline-offset: 3px`）。押す範囲は高さ 44px。乗せた：下線を 2px
- 「この記録を消す」：文字 `--negative` 14px、下線 1px。フォームの一番下、ほかのボタンから 24px 離す

### 返す組の行（このサービスだけの要素）

- 面の中に縦に並べる。行の高さ 64px、行の間に 1px の `--rule`。左右の余白 16px
- 左から：払う人の印（28px の丸、人の色、頭文字 12px Geist 500 / BIZ UDPゴシック 700）→ 6px → 名前（16px、`--text`、さんは付けない）→ 8px → 矢印 → 8px → 受け取る人の印 → 6px → 名前 → 12px 以上 → 右端に金額（24px 700、右揃え、後ろに 14px `--muted` の「円」）
- 2人の名前の欄は残りの幅を同じだけ分け合う（`flex: 1 1 0; min-width: 2em;`）。360px でも名前は最低2文字見える（頭文字が同じ「佐藤」と「佐々木」を、色だけで見分けさせないため）
- 矢印：幅 24px（PC は 40px）、線 2px `--signal`、先端は線で描いた「>」（8px）。`aria-hidden="true"`。読み上げには行全体に「田中さんが佐藤さんに6,210円返す」を付ける
- 名前は `min-width: 0` で、入りきらないときは「…」で省略する。金額は省略しない
- 金額の右端は、面の中のどの行でも同じ線に揃える
- 行は押せない（見るだけ）。並びは金額の大きい順

### ひとりずつの差し引き

- 行の高さ 48px。左に人の印（24px）と名前（14px）、真ん中に棒、右に言葉と金額（14px、右揃え、例：「受け取る 9,050円」「返す 6,740円」「0円」）
- 並び：`grid-template-columns: 24px 80px minmax(64px, 1fr) auto; column-gap: 8px; align-items: center;`（名前は 80px で、入りきらなければ「…」。言葉と金額の欄は内容の幅で、全部の行で右端を揃える）。PC の左の列（664px）では名前の欄を 120px にする
- 棒：高さ 6px、角丸 3px、色 `--control`。中央に縦の 0 の線（1px、`--border`、行の高さいっぱい）。受け取る人は 0 の線から右へ、返す人は左へ伸ばす。長さは、絶対値がいちばん大きい人を棒の幅の半分いっぱい（100%）にした割合。0円の人は棒を描かない
- 向きは棒の左右と言葉で伝え、色では分けない

### 立て替えの記録（一覧）

- 2行の行、高さ 64px、行の間に 1px の `--rule`
  - 1行目：何に（16px、`--text`、1行で「…」省略）、右端に金額（16px 700、右揃え、後ろに 12px の「円」）
  - 2行目：「10月28日 佐藤さんが払った（4人の分）」（12px、`--muted`）。全員の分でないときは「（佐藤・田中の分）」と名前を並べ、入りきらなければ「…」
- 行は `<button>`（押すと、その記録を直すフォームが開く）。乗せた：地 `--raised`。押した：地 `--raised`。フォーカス：共通の輪（`outline-offset: -2px`）
- 新しい順に5件。それより多いときは、面の下に「すべての記録（12件）」の文字のボタン（右揃え）を置く。押すと、その場で全部を出す
- 50件を超えたら、各行に `content-visibility: auto; contain-intrinsic-size: 64px;`

### 記録のフォーム（「立て替えを記録」）

並び順：金額 → 何に → 払った人 → 誰の分 → 日付 → 1人あたりの金額 → 「記録する」。欄の間は 16px。ラベルは欄の上（14px 700、欄との間 8px）。例の文字（placeholder）をラベルの代わりにしない。

- **金額**：高さ 56px、文字 24px 700（Geist、右揃えではなく左から）、右の内側に「円」（14px `--muted`）。`inputmode="numeric"`、`name="amount"`、`autocomplete="off"`。例「1,200」（`--muted`）。全角の数字や桁区切りを入れても受け付ける
- **何に**：高さ 48px、文字 16px。`name="memo"`、`autocomplete="off"`、例「スーパー、電気代…」
- **入力欄の共通**：地 `--surface`、枠 1px `--control`、角丸 6px、左右の余白 12px
  - 乗せた：枠 `--text`
  - フォーカス：枠 `--text` に、共通の輪
  - 使えない：地 `--ground`、文字 `--muted`（保存中だけ）
  - エラー：枠 2px `--negative`、欄の下 6px にエラーの文（14px、`--negative`、文の頭に「!」を丸で囲んだ 14px の印）。`aria-invalid="true"` と `aria-describedby`
- **払った人**：1人だけ選ぶ札（ラジオ）。札は高さ 44px、角丸 22px、左に人の印（24px）、名前 14px、左右の余白 4px・14px。横に並べ、入りきらなければ折り返す（間 8px）
  - 通常：地 `--surface`、枠 1px `--control`
  - 乗せた：枠 `--text`
  - 選んだ：地 `--primary`、文字 `#FFFFFF`、名前の後ろに ✓（12px）。人の印はそのまま
  - フォーカス：共通の輪（`:focus-within` で札全体に）
- **誰の分**：複数選ぶ札（チェックボックス）。1人だけ選ぶ「払った人」と形と選んだ見え方を変え、2つを取り違えないようにする。札は高さ 44px、**角丸 6px**（払った人は丸い 22px）、左に人の印（24px）、名前 14px、左右の余白 4px・12px。横に並べ、入りきらなければ折り返す（間 8px）。最初は全員を選んでおく（全部が黒く塗られて画面が重くならないよう、塗りは使わない）
  - 選んでいない：地 `--surface`、枠 1px `--control`、名前 `--muted`、✓ なし
  - 乗せた：枠 `--text`
  - 選んだ：地 `--surface`、枠 2px `--text`（余白を 1px 減らして大きさを変えない）、名前 `--text`、名前の後ろに ✓（12px、`--text`）
  - フォーカス：共通の輪（`:focus-within` で札全体に）
  - ラベルの右に「全員」の文字のボタン（全員を選ぶ。全員が選ばれていたら「全員はずす」）
- **日付**：`type="date"`、`name="date"`、`autocomplete="off"`、高さ 48px、最初は今日
- **札の名前**：払った人は `name="paidBy"`、誰の分は `name="sharedBy"`。札は `<label>` で包み、印・名前・✓ のどこを押しても選べる（押せない隙間を作らない）
- **1人あたりの金額**：フォームの下、「記録する」の上に、14px `--muted` で「1人あたり 1,155円（4人で割る）」。端数の扱いは仕様書に従い、その結果をここで先に見せる（記録の前に間違いに気づけるように）。金額か人が足りないときは「—」
- **送る**：押したら、エラーのある最初の欄にフォーカスを移す。保存中はボタンを使えなくし「記録中…」
- **スマホ・タブレット**：下からのシート。地 `--surface`、上の角だけ角丸 12px、高さは内容まで（最大 `92dvh`、中は縦に流れる、`overscroll-behavior: contain`）、影 `0 -8px 24px rgba(22, 24, 29, 0.12)`。後ろに `rgba(22, 24, 29, 0.4)` の幕。上に見出し「立て替えを記録」（16px 700）と、右に「閉じる」（2番目のボタン）。「記録する」はシートの一番下で、幅いっぱい・高さ 48px。開いたら金額の欄にフォーカスを移す（ダイアログに入ったフォーカスの置き場所として。すぐ金額を打てるように）。閉じたら「立て替えを記録」にフォーカスを戻す。Esc と幕を押しても閉じる。入力の途中で閉じるときは「入れた内容を捨てますか？」と確かめる（「捨てる」「入力に戻る」）。入力の途中でページを離れる・読み込み直すときは、ブラウザの確かめ（`beforeunload`）を出す（PC のフォームも同じ）
- **PC**：右の列に面として常に出す。見出し「立て替えを記録」。最初はどこにもフォーカスを置かない。「記録する」は幅いっぱい・高さ 48px
- **記録を直すとき**：同じフォームで、見出しは「記録を直す」、主なボタンは「変更を保存」、一番下に「この記録を消す」

### 知らせ（記録した・消した・失敗）

- 画面の下の中央（スマホは固定の帯のすぐ上 8px）、幅は最大 360px。地 `--text`、文字 `#FFFFFF` 14px、角丸 8px、余白 12px 16px、影 `0 4px 16px rgba(22, 24, 29, 0.16)`。`aria-live="polite"`
- 「記録しました」は 3秒で消える。「スーパーの記録を消しました」は右に「元に戻す」（文字 `#FFFFFF`、下線、押す範囲 44px）を付け、8秒出す。乗せている間とフォーカスがある間は消さない

## 8. 動き

画面が開いたときの入場の動きは付けない。動きは、押した反応と、何が変わったかを見せる所だけ。`prefers-reduced-motion: reduce` では、位置と大きさの動き（`transform`）を全部止める。シートと知らせは動かさずに `opacity` だけ 120ms で切り替える。乗せた・押したときの色の変化は 0ms。保存した直後の行の地（下の表）は、動きではなく「どこが変わったか」の知らせなので、`--raised` のまま 1.5秒置いてから 0ms で消す（知らせを消さないため）。

| 何が | いつ | 時間 | 曲線 | 動かす性質 |
| --- | --- | --- | --- | --- |
| ボタン・札・行の地 | 乗せた・押した | 80ms | `ease-out` | `background-color`、`border-color` |
| ボタン | 押している間 | 80ms | `ease-out` | `transform: scale(0.98)` |
| 記録のシート | 開く | 220ms | `cubic-bezier(0.2, 0, 0, 1)` | `transform: translateY(100%) → 0`。幕は `opacity 0 → 1` |
| 記録のシート | 閉じる | 160ms | `cubic-bezier(0.4, 0, 1, 1)` | 開くの逆 |
| 足した・直した記録の行 | 保存した直後 | 地が `--raised` から透明へ 800ms | `ease-out` | `background-color`（どの行が増えたか分かるように） |
| 返す組の金額 | 保存で金額が変わったとき | 地が `--raised` から透明へ 800ms | `ease-out` | `background-color`（どの組が変わったか分かるように）。数字を数え上げる動きはしない |
| 知らせ | 出る・消える | 160ms | `ease-out` | `opacity`、`transform: translateY(8px) → 0` |

- 動きの途中で押されたら、すぐその操作に応える（シートを閉じている途中にもう一度開ける）

## 10. 避けること

このサービスで起きやすい失敗：

- **返す向きの読み間違い**：「田中 6,210円 佐藤」のように向きが分からない並びにしない。必ず「払う人 → 受け取る人 → 金額」の順で、矢印を描く。読み上げにも向きを書く
- **お金の増減を赤と緑で塗る**：返す側を赤にすると、責めているように見える。言葉と棒の向きで伝える
- **桁の読み間違い**：桁区切りの無い金額、幅の揃わない数字、左揃えの金額。必ず `tabular-nums` で右揃え、桁区切り付き
- **金額を目立たせすぎる**：40px を超える金額、数字だけを大きく並べたタイル（「合計 48,620円」を大きな箱に入れる、など）。いちばん大きいのは返す組の金額（24px）
- **詰め込み**：最初の1画面にグラフや集計を並べて、返す組が下に押し出されること
- **押し間違い**：44px より小さい札やボタン。払った人と誰の分の札を、同じ形・同じ選んだ見え方にすること（払った人は丸い札を塗る、誰の分は角の札に太い枠と ✓。ラベルと 16px の間も必ず空ける）
- **名前の見分け**：頭文字の丸の色だけで人を見分けさせること（同じ頭文字の人がいる。名前は最低2文字見せる）
- **すぐ消える削除**：確かめずに消すこと。消したら「元に戻す」を出す
- **入力の途中で消える**：シートを閉じたとき、保存に失敗したときに、入れた内容を捨てない

「AIが作った感」のうち、この画面で起きやすい物：

- 数字を大きく並べたタイル、アイコンを色の丸に入れたカード、同じ角丸の箱をただ並べること
- グラデーション、影を付けた面、ガラス風のぼかし
- ピル型の色付きバッジの多用（「精算済み」を緑のピルにする、など）
- 「おかえりなさい」などのあいさつの見出し、絵文字
- 大文字の小さなラベルを見出しの上に置くこと、「A・B・C」のように中黒でつないだ補足（2行目は文で書く）
- 文字やボタンに「→」を付けること（矢印は返す組の向きを示す所だけ）
- 等幅書体を小さなラベルに使うこと
- 色相を枠・見出し・ボタンに広げること（色相は矢印とフォーカスだけ）
- 暗い画面に明るい緑1色のような、配色の決まり文句

- PC の並び：「ひとりずつの差し引き」を右の列のフォームの下から、左の列の「返す人と金額」の下へ移した（見たい情報の3番目が、1024×768 で最初の1画面の外に出ていたため）。右のフォームは sticky にした
- 上のバー：固定かどうかが書かれていなかったので、固定しないと決め、線の決まりを消した（下の帯と合わせて、スマホで見える高さが減るため）
- 払った人と誰の分の札：同じ見え方で、「避けること」の押し間違いと食い違っていた。誰の分を角丸 6px・太い枠と ✓ に変え、全員を選んだときに黒い札が並ぶのも防いだ
- 返す組の名前：360px で名前がほぼ潰れ、頭文字が同じ人を色だけで見分けることになっていた。名前の欄の分け方と最低2文字を決めた
- 差し引きの行：棒と名前の幅が決まっていなかったので、grid の列を書いた
- 太さの決まりが「700 は金額と h1 だけ」と「見出しは 700」で食い違っていたので、700 を使う所を並べ直した。頭文字は日本語なので Geist 500 の指定を直した。h2 と `text-wrap: balance` を足した
- `prefers-reduced-motion` で、保存した行の目印まで 0ms で消えて「どこが変わったか」が分からなくなっていたので、1.5秒残すようにした。シートと知らせは透明度だけで切り替える
- web-design-guidelines に合わせて足した物：「乗せた」を `@media (hover: hover)` の中だけに、`-webkit-tap-highlight-color`、✓ などを SVG に（絵文字で出るのを防ぐ）、日付と札の `name`、札を `<label>` で包む、入力の途中の `beforeunload`、PC のメニューの文字と開いたときのフォーカス、タブレットのシートの幅、BIZ UDPゴシックの `preload: false`
