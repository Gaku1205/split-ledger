# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

友達やルームメイトと立て替えたお金を記録し、誰が誰にいくら返せばいいかを一目で確認できる精算ページ。（元のメモ：友達やルームメイトと立て替えたお金を記録して、誰が誰にいくら返せばいいか一目で分かるページ）

## 前提

- 使う人・使う場面（デザイン部門の分析。推定を含む）：
  - 使う人：一緒に暮らすルームメイト（2〜4人）や、旅行・飲み会の友達（3〜6人）。スマホのアプリには慣れているが、表計算で割り勘を組む手間はかけたくない（推定）
  - 使う場面（記録）：立て替えた直後に、レジを出た所や帰り道で、立ったまま片手で1回15〜30秒。週に数回、旅行中は1日に何回も（推定）
  - 使う場面（精算）：月末や旅行の最後に、1台のスマホを何人かで覗くか各自のスマホで開き、1〜3分で「誰が誰にいくら返すか」を確かめる（推定）
  - 端末はスマホが主。PC は、家で記録をまとめて見直すときだけ（推定）
- 技術：Next.js（App Router）＋TypeScript、テストはVitest

## 画面

ページは `/`（精算ページ）の1つだけ。見た目と文言は `docs/design.md` に従う。

### 精算ページ（`/`）

上から「上のバー → グループ名（h1）と要約 → 返す人と金額 → ひとりずつの差し引き → 立て替えの記録」を出す。PC（1024px 以上）は右の列に記録のフォームを常に出し、それより狭い画面は下に固定した「立て替えを記録」から下のシートでフォームを開く。

#### グループとメンバー

- グループは1つだけ。グループ名の初期値は「みんなの精算」（名前の変更はまだできない）
- メンバーは上のバーの「メニュー」から開くシートで足す。名前を1つ入れて「足す」を押す
  - 名前は前後の空白を取ってから確かめる。空なら「名前を入れてください。」、同じ名前（前後の空白を取って同じ文字）のメンバーがいれば「同じ名前のメンバーがいます。別の名前にしてください。」を欄の下に出し、足さない。入れた文字は消さない
  - 足せたら欄を空にし、欄にフォーカスを残す（続けて足せるように）
- メンバーは6人まで。6人いるときは入力欄と「足す」を使えなくし、「メンバーは6人までです。」を出す
- 人の印の色は、メンバーに足した順に1〜6（7人目からは1に戻る。上限が6人なので今は戻らない）
- メンバーの削除・名前の変更はまだできない

#### 立て替えの記録

- 1件の記録は、金額・何に・払った人（1人）・誰の分（1人以上）・日付
- 記録できるのはメンバーが2人以上のとき。2人より少ないときは「返す人と金額」の面に案内の文と「メンバーを足す」（主なボタン）を出し、下に固定の帯のボタンも「メンバーを足す」にする（押すとメニューのシートが開く）。PC の右の列のフォームは出さない
- 金額
  - 1円単位の整数。全角の数字（０〜９）、桁区切り（`,` と `，`）、前後と途中の空白は取り除いてから読む
  - 空・0 は「金額を入れてください（1円以上）。」、数字以外が混ざる（小数点・マイナスも含む）・大きすぎる（`Number.MAX_SAFE_INTEGER` を超える）は「金額は数字で入れてください。」
- 何に：自由な文字。前後の空白を取る。空でもよい（一覧では「—」を出す）
- 払った人：最初は誰も選ばない。選ばずに記録すると「払った人を選んでください。」
- 誰の分：最初は全員を選ぶ。1人も選ばずに記録すると「誰の分かを1人以上選んでください。」。払った人が入っていなくてもよい（払った人は立て替えただけで、分け前は無し）
- 日付：最初は今日（ブラウザの日付）。未来の日付も記録できる。空のまま記録したら今日として扱う
- 「記録する」を押すと全部の欄を確かめ、エラーがあれば欄の下にエラーの文を出し、エラーのある最初の欄（金額 → 払った人 → 誰の分の順）にフォーカスを移す。入れた内容は消さない。エラーは、その欄を直すと消える
- 記録できたら「記録しました」を3秒出し、返す組・差し引き・要約・記録の一覧をすぐ更新する。スマホ・タブレットはシートを閉じ、PC はフォームを最初の状態（金額・何に・払った人が空、誰の分は全員、日付は今日）に戻す
- 「1人あたり」：金額と誰の分がそろっているとき、切り捨てた1人分を「1人あたり 1,155円（4人で割る）」と出す。割り切れないときは「1人あたり 1,155円（4人で割る・端数は1円ずつ上乗せ）」。そろっていないときは「1人あたり —」
- 入力の途中（金額・何に・払った人のどれかが入っている、誰の分が全員でない、日付が今日でない）にシートを閉じる（「閉じる」・Esc・幕）ときは「入れた内容を捨てますか？」と確かめる。「捨てる」で閉じて内容を捨て、「入力に戻る」でシートに戻る。入力の途中でページを離れる・読み込み直すときは `beforeunload` でブラウザの確かめを出す（PC のフォームも同じ）
- 記録を直す・消す・元に戻すはまだできない（一覧の行は押せない）

#### 分け方（1件の立て替え）

- 均等割りだけ。誰の分の人数を n として、1人分は `floor(金額 ÷ n)`
- あまり（`金額 − 1人分 × n` 円）は、誰の分の人へ **メンバーに足した順** に1円ずつ足して配る。分け前の合計は必ず元の金額と一致する
  - 例：1,000円を3人（足した順に A・B・C）で → A 334円、B 333円、C 333円

#### ひとりずつの差し引き

- 差し引き ＝ そのメンバーが払った金額の合計 − そのメンバーの分け前の合計。正なら「受け取る」、負なら「返す」、0 なら「0円」
- 全員の差し引きの合計は必ず 0円になる
- 並びはメンバーに足した順

#### 返す組の求め方

- 差し引きが正の人（受け取る人）と負の人（返す人）を、それぞれ金額の絶対値の大きい順（同額ならメンバーに足した順）に並べる
- いちばん大きく返す人から、いちばん大きく受け取る人へ、2人の残りの小さいほうの金額を返す組を1つ作る。2人の残りを減らし、0 になった人を外して並べ直し、どちらかがいなくなるまで繰り返す（貪欲法。返す回数がなるべく少なくなる）
- 出すときは金額の大きい順（同額なら、払う人のメンバーに足した順、次に受け取る人の足した順）
- 立て替えが0件なら「まだ立て替えがありません。…」、1件以上あって全員が0円なら「全員の差し引きが0円です。返すお金はありません。」を出す

#### 要約と一覧

- 要約は「4人で12件、合計48,620円」（メンバーの数、記録の件数、金額の合計）。記録が0件なら「3人で0件」
- 記録の一覧は日付の新しい順（同じ日付なら後から記録した方が上）に5件。6件以上あれば「すべての記録（N件）」を出し、押すとその場で全部出す
- 一覧の2行目は「10月28日 佐藤さんが払った（4人の分）」。誰の分が今のメンバー全員なら「（N人の分）」、そうでなければ「（佐藤・田中の分）」とメンバーに足した順に名前を並べる。日付は今年でなければ「2025年10月28日」のように年も出す

#### 保存

- 保存先はブラウザの `localStorage` だけ（サーバー・ログイン・端末間の共有は無い）。キーは `split-ledger:v1`
- 保存の形（JSON）：

```json
{
  "version": 1,
  "groupName": "みんなの精算",
  "members": [{ "id": "m_…", "name": "佐藤" }],
  "expenses": [
    {
      "id": "e_…",
      "amount": 4620,
      "memo": "スーパー",
      "paidBy": "m_…",
      "sharedBy": ["m_…", "m_…"],
      "date": "2026-10-28",
      "createdAt": 1793180000000
    }
  ]
}
```

- `members` の並びがメンバーに足した順。`date` は `YYYY-MM-DD`、`createdAt` はミリ秒
- 読み込むとき、値が無い・JSON として読めない・形が違う（`version` が 1 でない、必要な項目の型が違う）ときは、空（グループ名は初期値、メンバーと記録は0件）として扱う。いないメンバーを指す記録は捨てる
- ページを開いた直後、`localStorage` を読むまでは「読み込み中」の表示を出す（サーバーでは読めないため）
- メンバーを足す・記録するたびに全体を書き込む。`localStorage` が使えずに書き込めなかったときだけ、記録のフォームに「記録を保存できませんでした。…」を出し、入れた内容はそのまま残す（メンバーを足すときに書き込めなかったら、メニューのシートの「足す」の下に「メンバーを保存できませんでした。…」を出し、入れた名前はそのまま残す）
