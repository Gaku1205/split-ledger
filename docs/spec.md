# 仕様書

アプリの「何を・どう動かすか」を書く。AIは作業の前に必ずここを読む。

## 目的

友達やルームメイトと立て替えたお金を記録し、誰が誰にいくら返せばいいかを一目で確認できる精算ページ。（元のメモ：友達やルームメイトと立て替えたお金を記録して、誰が誰にいくら返せばいいか一目で分かるページ）

## 前提

- 使う人・使う場面（デザイン部門の分析。推定を含む）：
  - 使う人：一緒に暮らすルームメイト（2〜4人）や、旅行・飲み会の友達（3〜6人）。スマホのアプリには慣れているが、表計算で割り勘を組む手間はかけたくない（推定）
  - 使う場面（記録）：立て替えた直後に、レジを出た所や帰り道で、立ったまま片手で1回15〜30秒。週に数回、旅行中は1日に何回も（推定）
  - 使う場面（精算）：月末や旅行の最後に、1台のスマホを何人かで覗くか各自のスマホで開き、1〜3分で「誰が誰にいくら返すか」を確かめる（推定）
  - 端末はスマホが主。PC は、家で記録をまとめて見直すときだけ（推定）
- 技術：Next.js（App Router）＋TypeScript、テストはVitest
