# split-ledger

友達やルームメイトと立て替えたお金を記録し、誰が誰にいくら返せばいいかを一目で確認できる精算ページ。

- 仕様：[docs/spec.md](docs/spec.md)
- 見た目：[docs/design.md](docs/design.md)

[ai-dev-template](https://github.com/Gaku1205/ai-dev-template) の工場で、1行のメモ（友達やルームメイトと立て替えたお金を記録して、誰が誰にいくら返せばいいか一目で分かるページ）から作ったサービスです。Issue を書くと、AI が清書・実装・レビュー・マージまで進めます（[docs/pipeline.md](docs/pipeline.md)）。
